# Whatagraph Agent Skills

Source repository for the [Agent Skills](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview) served by the Whatagraph MCP server.

Skills are loaded by the MCP server on demand via its `list-skills` / `load-skill` tools — there is no separate install step. Rollout is gated; if skills aren't available for your account yet, reach out to Whatagraph support.
